# Scale Up session 1

AWS-branded HTML deck adapted for Daniel Wirjo.

## Edit

Run:

```bash
./edit.sh
```

The editor opens in your browser. Use Text, Layout, and Style modes, then export a single HTML file or ZIP from the toolbar.

## Present

Open `index.html` through a local server, or use the editor's Present mode. Press the left and right arrow keys to navigate and `N` to open speaker notes.
