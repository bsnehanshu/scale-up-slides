# AI features from prototype to production

AWS-branded HTML deck for the Melbourne Scale Up session, presented by Snehanshu Bhaisare. Based on Daniel Wirjo's `ai-to-production` deck, with a healthcare field story, audit checklist, and a Claude Code on Bedrock demo video added as slides 29–31.

## Edit

Run:

```bash
./edit.sh
```

The editor opens in your browser. Use Text, Layout, and Style modes, then export a single HTML file or ZIP from the toolbar.

## Present

Open `index.html` through a local server, or use the editor's Present mode. Press the left and right arrow keys to navigate and `N` to open speaker notes.
